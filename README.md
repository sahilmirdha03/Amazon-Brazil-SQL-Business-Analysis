# 🛒 Amazon Brazil – SQL Business Analysis

## 📌 Project Overview

This project focuses on analyzing Brazilian e-commerce business data using **MySQL** to uncover meaningful business insights related to sales performance, customer behavior, seller performance, product categories, payment trends, and delivery operations.

The analysis covers 14 real-world business questions using SQL queries to explore the dataset and identify trends, patterns, and potential business opportunities.

## 🎯 Project Objectives

- Analyze seller performance across Brazilian states.
- Identify top-performing product categories by revenue.
- Understand customer purchasing and payment behavior.
- Evaluate customer satisfaction through product reviews.
- Analyze order trends and delivery performance.
- Identify inactive sellers, unpurchased products, and customers without reviews.

## 🛠️ Tools & Technologies

- **Database:** MySQL
- **SQL Concepts:** Joins, Aggregate Functions, GROUP BY, HAVING, Subqueries, CTEs, Window Functions, CASE Statements, Date Functions, and NULL Handling.
- **IDE:** MySQL Workbench

## 📊 Dataset Overview

The project uses Brazilian e-commerce data containing multiple interconnected tables:

| Table Name | Description |
|---|---|
| customers | Customer information |
| sellers | Seller details |
| products | Product information |
| orders | Order details |
| order_items | Purchased item details |
| order_payments | Payment information |
| order_reviews | Customer review data |

## 🔍 Business Questions Solved

The project addresses 14 business questions:

1. Find the total number of orders fulfilled by each seller state.
2. Calculate cumulative revenue generated by each product category over time.
3. Identify the most-used payment method and average order value for each payment type.
4. Find the customer who spent the most money across all orders.
5. Calculate the average review score for each product category.
6. Find the total number of orders placed by each customer, broken down by customer state.
7. Identify sellers who registered on the platform but never fulfilled an order.
8. Find the top 5 product categories by total revenue.
9. Calculate the median delivery time between order placement and actual delivery.
10. Identify products that have never been ordered.
11. Find sellers who have fulfilled more orders than the platform's average seller.
12. Identify Brazilian states with the highest average customer review scores.
13. Identify customers who placed orders but never left a review.
14. Find the month with the highest number of orders across the platform.

## 💡 Key Business Insights

- **Seller Performance:** The leading seller fulfilled 200 orders, compared with an average of approximately 32.31 orders per seller.
- **Inactive Sellers:** 84 sellers had no delivered orders.
- **Revenue Leaders:** Beauty & Health generated the highest category revenue, followed by Watches & Gifts.
- **Customer Satisfaction:** Amapá recorded the highest average review score of approximately 4.194.
- **Delivery Performance:** The median delivery time was 10 days.
- **Order Trends:** August recorded the highest order volume, with 10,843 orders.
- **Payment Trends:** Credit cards were the most-used payment method, accounting for 76,795 payments.
- **Customer Reviews:** 90 customers in the analyzed result set had no review.
